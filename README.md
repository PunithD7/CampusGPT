# CampusGPT

A static HTML-based AI college assistant that uses the Gemini API from the browser for local testing.

## Files

- `index.html` — complete app UI and logic

## Run locally

Open `index.html` in a browser.

Then add your own Google Gemini API key in the AI settings panel.

## Security note

This project is for local testing only. Do not publish a file containing your personal API key.
